## 🛠️ الشرح التفصيلي لجميع المشاريع والأكواد

### 1️⃣ مشروع الآلة الحاسبة (`Week01.Calculator`)

يتضمن الكود تنفيذ آلة حاسبة تفاعلية مع حماية المدخلات باستخدام `try-catch` و `while (true)`.

#### **آلية العمل:**

1. **قراءة المدخلات:**
   * قراءة العدد الأول (`FN1`) وتحويله باستخدام `Convert.ToInt32()`.
   * قراءة العملية الحسابية (`OP`).
   * قراءة العدد الثاني (`SN2`) وتحويله بنفس الطريقة.

2. **العمليات الحسابية المدعومة:**
   * **الجمع (`+`):** `FN1 + SN2`
   * **الطرح (`-`):** `FN1 - SN2`
   * **الضرب (`*`):** `FN1 * SN2`
   * **القسمة (`/`):** `FN1 / SN2`
   * **باقي القسمة (`%`):** `FN1 % SN2`

3. **التحقق والاستثناءات:**
   * في حال إدخال رمز عملية غير مدعوم، يتم طباعة `Invalid Operation! Please try again.` وإعادة المحاولة عبر `continue`.
   * في حال إدخال قيم غير رقمية، يتم التقاط الاستثناء بطباعة `e.Message` وتكرار الحلقة.
   * تنتهي الحلقة بـ `break` فور إتمام العملية بنجاح.

### 2️⃣ مشروع حساب وتقييم درجات الطلاب (`Week01.StudentGrades`)

يقوم هذا البرنامج بإدخال اسم الطالب ودرجاته في ثلاث مواد، ثم حساب المتوسط الحسابي والتقدير.

#### **آلية العمل:**

1. **إدخال البيانات:**
   * قراءة الاسم الكامل للطالب (`string name`).
   * قراءة 3 درجات: `M1`, `M2`, `M3`.

2. **التحقق من صحة الدرجات (Validation):**
   * يتم التحقق من الشرط:
     `M1 >= 0 && M1 <= 100 && M2 >= 0 && M2 <= 100 && M3 >= 0 && M3 <= 100`
   * إذا كانت إحدى الدرجات خارج هذا النطاق، يطبع البرنامج:
     `Invalid Enter . Plase Re-Enter The Marks ( 0 - 100) .`
     ثم يعيد المحاولة باستخدام `continue`.

3. **حساب المتوسط الحسابي (`Avg`):**
   * `Sum += M1 + M2 + M3;`
   * `Avg = Sum / NumOfMarks;` (حيث `NumOfMarks = 3`).

4. **تحديد التقدير النهائي:**
   * **`Avg >= 90`** 👈 `(A)`
   * **`Avg >= 80`** 👈 `(B)`
   * **`Avg >= 70`** 👈 `(C)`
   * **`Avg >= 50`** 👈 `(D)`
   * **أقل من 50** 👈 `(F)`

5. **معالجة الأخطاء:**
   * حماية الكود عبر `try-catch (Exception ex)` مع `continue` عند إدخال بيانات غير صحيحة.

### 3️⃣ مشروع المسائل البرمجية الـ 10 (`Week01.ProgrammingProblims10`)

يحتوي الكلاس على 10 دوال برمجة مستقلة تهدف لترسيخ المفاهيم الأساسية للألغوريتمات:

#### **1. `Even_Or_Odd()` — فحص العدد زوجي أو فردي**
* يطلب إدخال رقم `num` كـ `double`.
* يفحص باقي القسمة على 2 (`num % 2 == 0`).
* يطبع ما إذا كان الرقم **Even** أو **Odd** مع وجود حماية `try-catch`.

#### **2. `MaxNumber()` — إيجاد أكبر رقم**
* يطلب إدخال أرقام متتالية بحلقة `while (true)`.
* يتوقف التكرار عند إدخال `-1`.
* يستبدل القيم ويحدث قيمة `max` باستخدام `Math.Max(d, num)`.
* يرجع أعلى رقم تم إدخاله (`double max`).

#### **3. `SumNum()` — جمع الأعداد المنسقة**
* يطلب إدخال أرقام ويضيفها للمتغير `sum`.
* يتوقف عند إدخال الرقم `-1`.
* يرجع المجموع الكلي للأعداد المدخلة.

#### **4. `Multiplication_Table()` — جدول الضرب**
* يطلب إدخال رقم جدول الضرب `num`.
* يستخدم حلقة `for (int i = 1; i <= 12; i++)` لطباعة جدول الضرب بنسق منظم.

#### **5. `Sum_Array()` — جمع عناصر مصفوفة**
* يطلب تحديد حجم المصفوفة `size`.
* ينشئ مصفوفة من نوع `double[] arr = new double[size];`.
* يجمع كافة الأعداد المدخلة ويدخلها للمصفوفة ثم يرجع المجموع الكلي `sum`.

#### **6. `Reverse_The_Text()` — عكس النص**
* يقرأ النص ويحوله إلى أحرف صغيرة `text.ToLower()`.
* يمر بحلقة `for` عكسية من `text.Length - 1` حتى `0` لتجميع النص المعكوس.
* يرجع النص بعد عكسه.

#### **7. `Palindrome()` — فحص النص التناظري (Palindrome)**
* يقبل نصاً، يقوم بعكسه بنفس آلية `Reverse_The_Text()`.
* يقارن النص المعكوس بالنص الأصلي `if (reverse == text)`.
* يطبع `Is Palindrome` أو `Is Not Palindrome`.

#### **8. `Count_Vowels()` — حساب حروف العلة**
* يقرأ الكلمة أو الجملة ويحولها لـ `ToLower()`.
* يفحص كل حرف بحلقة تكرارية، وإذا كان من ضمن الحروف (`a, e, i, o, u`) يزيد العدّاد `count++`.
* يرجع إجمالي عدد الحروف المتحركة.

#### **9. `Prime()` — فحص الرقم الأولي**
* يطلب إدخال رقم وفحصه لمعرفة ما إذا كان رقماً أولياً.
* يحتوي على حماية مدخلات عبر `try-catch`.

#### **10. `Factorial()` — حساب المضروب (Factorial)**
* يطلب رقم `num` ويضيف قيمته للمتغير `f`.
* يمر بحلقة تكرارية تنقص تدريجياً (`i = num - 1; i > 0; i--`) لضرب `f *= i`.
* يرجع النتيجة النهائية لمضروب العدد.
